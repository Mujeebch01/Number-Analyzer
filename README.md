Number Analyzer (C++)

This is a simple C++ program that takes 10 numbers from the user and performs basic analysis on them.

📌 Features
The program calculates:
- Sum of all numbers
- Average of numbers
- Largest number
- Smallest number

🧠 How it Works
1. User enters 10 integer values
2. Program stores them in an array
3. Functions are used to:
   - Calculate sum
   - Find average
   - Find maximum value
   - Find minimum value

💻 Functions Used
Sum() → Calculates total sum
avg() → Calculates average
large() → Finds largest number
Small() → Finds smallest number


🚀 How to Run
1. Open file in any C++ compiler (CodeBlocks / VS Code)
2. Compile the program
3. Run it and enter 10 numbers
